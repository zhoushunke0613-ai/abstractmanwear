# Abstract Manwear

## Design Context

### Users
Global B2B buyers — wholesalers, private-label brands, distributors, importers, cross-border sellers — evaluating a men's underwear manufacturer from Europe, US, and Australia. They're reading this during sourcing research, often on desktop, with skepticism. They need to trust the capability before they inquire.

### Brand Personality
Authoritative, considered, unostentatious. Three words: *archival, disciplined, exacting*. The feel of a small atelier that has done this for a long time and has no need to shout.

### Aesthetic Direction
Editorial Atelier — publication-style layouts, oversized display serifs, hairline rules, numbered sections, left-aligned asymmetric compositions. Anti-references: SaaS dashboards, hero-with-gradient landing pages, glass-morphism cards, dot grids, stock-photo manufacturing imagery. References: *Monocle* magazine spreads, Hermès manufactory books, Officine Generale, CDLP.

### Design Principles
1. **Typographic hierarchy carries the design**. Layout is restraint; type is expression. Oversized display serif + precise sans body. Numbers are design elements.
2. **Asymmetric, left-aligned compositions**. Break grid intentionally. Never center everything.
3. **Hairline rules, not cards**. Structure comes from horizontal lines and whitespace, not bordered rectangles.
4. **Monochrome with a single accent**. Warm linen → espresso, with one muted terracotta for emphasis. No gradient text ever.
5. **Quiet motion**. Subtle reveal on load and underline animations on links. No elastic bounces.
